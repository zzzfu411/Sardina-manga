# 云漫第一轮成熟度优化：交付记录

日期：2026-09-22。依据：[质量审计](2026-09-22_成熟漫画软件对标与质量审计.md)、[执行计划](2026-09-22_优化执行计划.md)。

本轮按照 Intent → Spec → Impl 完成 A–E 执行包。主任务负责书架、身份与集成，三个 Agent 分别处理源数据、推荐、阅读器，并对书架进行了独立复核。审计 F01–F10 均已有实现和回归覆盖；推荐、逐章状态、阅读尺寸与可选自动追更已接入实际页面。本地 `http://127.0.0.1:8765` 已运行新版本，刷新页面即可使用。

## 1. 审计问题落实

| 问题 | 最终处理 | 验收证据 |
|---|---|---|
| F01 备份导出后无法导回 | 版本 2 备份统一读写契约与 50 MB 文件上限，兼容 v1；保留未知源记录 | 浏览器导出 2,814,336 字节、301 本合成书架，清空独立测试存储后导入，恢复 301 本；模型往返校验内容一致 |
| F02 超过 300 本静默淘汰 | 去掉数量截断，逐本写入；区分明确收藏与阅读记录，提供只看收藏；写入失败明确提示 | 300＋1 本、存储超额、删除后重载、跨标签不同记录修改均有回归；不宣称突破浏览器容量限制 |
| F03 缺页章节伪装完整 | DM5 家族对可信声明页数核对最终图片数；不足、重复导致不足或超额明确失败 | 声明 6 页只得 2 页时拒绝成功，不进入成功缓存；没有声明总数的旧源不虚构完整性 |
| F04 拷贝分页重复漏章 | 按分组验证稳定总数、分页结构与独立章节 ID | 重叠、单页重复、总数变化、提前空页均失败；正常多组目录保持原序 |
| F05 挑战页伪装空搜索 | 七个旧 HTML 适配器区分明确零结果、访问挑战与无法识别的结构 | 合法空页仍成功；挑战和结构变化返回源错误；六份真实搜索 HTML 已离线回放 |
| F06 完整但部分锁定目录不能追更 | `catalogCompleteness` 与 `unavailableReason` 独立表达 | 明确完整的受限目录可比较更新，保留章节阅读限制；未知／部分目录不冒充新确认的完整目录 |
| F07 自动跨语言换章 | NamiComi 保留全部章节，提供语言与 `sequenceId`；阅读器在当前明确序列内找前后章 | 英文末章停止，目录仍可手动进入西语；未知语言单独成序列 |
| F08 推荐同名异作者丢失 | 后端保留来源条目；前端仅按可信身份与作者、版本证据合并 | 同名异作者、无作者的不同来源保守保留；有证据的同作保留来源变体 |
| F09 官方副标题命中被折叠 | 适配层保留 `alternateTitles`／`matchedTitle`，相关性计算消费这些证据 | 泰拉 `rhine lab` 命中进入主结果，展示主标题不变；不把简介或猜测当别名 |
| F10 嬉皮新旧地址断开进度 | 对可信域名与源内 ID 生成稳定书籍键，读取和合并使用同一规则 | 同一 mid 的旧／新作品地址合并并保留较新进度；不同 ID、未知域名不会误并 |

源适配细节见[源数据交接](../output/iteration-20260922/source-data/handoff.md)。本轮修复的是可复现的契约问题，没有把「注册 25 源」改写为「所有源和章节实时可读」。

## 2. 用户能直接使用的变化

### 推荐

- 从 25 个已注册源的发现能力中轮换，当前为 48 个来源／模式选择、8 个服务端批次。每个批次最多读取 6 个列表，各列表最多取 40 本，候选上限 200；来源执行全局并发 3。单次前端动作最多串行补充 2 批，通常首载 1 批，不同时请求全部来源。
- 每次显示 12 本，已有未见候选时优先展示，不再到第三批就固定回到第一批。候选不足继续有界补充；耗尽后明确停止循环。
- 明确收藏是较强信号，试读与旧记录是弱信号。结合有证据的作者、内容词线索、近期曝光及来源／作者多样性排序，卡片显示真实理由和封面。
- 「不感兴趣」即时生效、可以撤销；可关闭书架偏好、清空推荐记录。曝光记录以进入可见区域并停留为准，默认保存在本机，保留最近 28 天且最多 600 条；忽略记录最多 300 条。
- 当前卡片收藏后保留位置并显示状态，新一批过滤在架作品。封面失败可尝试已知同作来源、手动重试；失败来源不清空其他推荐。
- 推荐与发现复用每个列表的 5 分钟缓存；推荐聚合使用独立缓存，避免嵌套缓存锁。页面软过期刷新保留当前卡位与后续游标。

这仍是**可解释规则基线**，不是训练过的协同过滤模型。真实首批样本中只有 89/143 条含作者、9/143 条含描述，内容词线索仅覆盖 7/143 条；不能据此宣称已经充分理解每部漫画或提升了真实点击率。完整实现与离线回放见[推荐交接](../output/iteration-20260922/recommendations/handoff.md)。

### 书架、进度与追更

- 逐章已读／未读是明确操作，与最后阅读位置、整本分类和更新通知分开；跳到末页不自动认定读完。
- 采用记录级 `localStorage` 保存、删除标记和跨标签合并。旧 v1 原始数组保留为只读基础，新格式仅保存变化，避免启动时把大书架完整复制一遍。
- 独立复核提出的三处边界均已修复：容量不足时仍可提交删除；跨标签已读按钮按其显示的目标执行并同步刷新；页面退出时同步提交仍待写入的进度。相关故障注入与浏览器同步检查均通过。
- 存储失败会提示，保留内存变更并提供书架导出及原始恢复记录导出。原始恢复记录是排错恢复证据，不能当作普通 v1／v2 书架文件直接导入。
- 可选自动追更默认关闭。开启后，在页面可见时检查近期读过且已过期的连载，每本至少间隔 6 小时、每轮最多 20 本、并发 2；隐藏页面或关闭选项会停止当前自动检查。手动追更仍可使用。

普通备份包含书籍、收藏、分类、最后位置、逐章状态与目录检查记录，**不包含**阅读器设置、推荐反馈或常用源偏好。50 MB 是备份文件接受上限，不是浏览器可保存容量保证；本轮也没有引入跨设备同步。

### 阅读器

- 提供适宽／整页、100%–300% 放大、双击切换放大、平移；393px 视口下 200% 图片实际宽度为 786px。
- 阅读模式、尺寸等设置按单书保存，可恢复全局默认或将当前设置设为默认。保留原有键盘、连续／逐页模式及页内位置恢复。
- 已读状态跨标签同步到阅读器和详情目录；同步不改变当前阅读位置。
- 长章节每 80 页分批创建节点，批间让出主线程；提交前检查章节代次。布局一次读取视口尺寸，再集中写样式，避免逐页读写交错。
- 构建途中切章／关闭不会插回旧节点，也不会覆盖原有有效进度；恢复末段只加载邻近图片，保持图片请求并发上限 4。

本轮没有对 500 页 DOM 做窗口化，也没有为已解码图片实现应用层离屏淘汰；真实图片内存仍需要后续测量。触摸事件保留浏览器原生双指缩放路径，验收使用模拟手机视口，未作物理手机手势测试。

### 真实来源抽样

- 17:48 的首批样本：6 个来源成功，143 条带封面地址候选，2.413 秒，无来源警告。此处「有封面地址」不等于当时逐图下载验证。
- 18:18 的新服务样本：包子连接失败，其余 5 源仍返回 107 条候选，总响应 12.572 秒，并显示包子的失败原因。[服务抽样](../output/iteration-20260922/live-server-smoke.json)还记录了《ONE PIECE航海王》封面经本地代理返回 200、JPEG 180×240 并完整解码；随后真实浏览器验证首 6 张卡片封面解码成功。

两次结果说明网络和来源会波动，不能以一次成功外推所有批次或全部章节的可用率。七源搜索探查中漫画柜的一次 TLS 超时同样保留在记录内，没有降低 TLS 校验来制造成功。

### 长章节受控测量

| 样本 | 初版元数据与 DOM 准备 | 最终准备 | 最终目标页就绪 | 最终观测到的 ≥50ms 长任务 |
|---|---:|---:|---:|---|
| 180 页 | 32.5ms | 21.1ms | 124.9ms | 无 |
| 500 页 | 72.0ms | 41.3ms | 138.2ms | 无 |

500 页初版观测到一次 67ms 长任务；只分批创建仍有约 68ms，进一步消除布局的反复尺寸读取后，本轮复测未再观测到。1000 章目录展开 22.1ms，精确搜索 1.4ms。这是单次本机 Chromium 合成测量，图片响应固定延迟 80ms，包含自动化调度开销；不是跨设备性能承诺，也未测真实大图解码内存。500 页仍有 500 个页面容器、3090 个阅读器节点。详见[前后测量与限制](../output/playwright/reader-20260922/README.md)。

## 4. 后续实施顺序

本轮优先完成已确认的可靠性问题和可独立交付的体验改进。以下为下一阶段执行队列，不计入本轮已完成能力：

| 顺序 | 实施内容 | 开工前需要明确的输入 | 完成标准 |
|---|---|---|---|
| 1 | 统一作品／版本记录、完善元数据 | 各源真实作者、别名、语言、题材的字段与可信度；原作／重制／彩版样本 | 字段保留出处；同名异作、同作异版样本不能误合；未知值显式保留 |
| 2 | 内容推荐 v2 与可保存筛选 | 第一阶段元数据覆盖率，以及本地阅读／明确反馈样本 | 加入可跳过的题材／语言偏好；建立固定离线回放集，比较去重、覆盖、多样性与负反馈命中，不把规则分数当准确率 |
| 3 | 完整应用备份与更大本地存储 | 选择 IndexedDB 或本机 SQLite 的存储边界，统一所有设置 schema | 书架、阅读设置、推荐反馈、源偏好一起恢复；中断迁移、旧版本导入、容量不足均可恢复 |
| 4 | 可核对的换源迁移 | 章节／卷／版本对应样本和无法对应的反例 | 展示目标来源及目录差异；不确定时手选章；迁移失败保留原进度，不自动照搬跨源页码 |
| 5 | 阅读器窗口化与图片内存管理 | 真实普通长章在目标设备上的内存／卡顿测量 | 限制 DOM 和解码图片驻留；快速跳页、缩放、失败重试与恢复位置均不退化 |
| 6 | 离线与跨设备同步 | 离线内容范围、容量与清理方式；同步身份及冲突规则 | 离线队列可恢复、可清理；同步冲突不丢进度／删除；先完成迁移与完整备份，再接入同步 |

协同过滤需要真实多用户数据；当前不把引入账号、复杂服务或大模型作为推荐改进的前置条件。原始实现快照保存在 `output/iteration-20260922/before-source.tar.gz`，便于比较本轮改动；该快照不包含用户浏览器书架。
