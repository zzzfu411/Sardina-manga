# Sardina 品牌与前端改版

日期：2026-09-23。用户最终选择 **#97 C「侧身阅读」**，已用于首页、页头和网站图标。产品名称统一为 **Sardina**，附属字标为 **manga**。

## Intent：恢复访问，建立简洁的漫画品牌

本轮开始时，本机 8765 端口没有服务监听。项目文件仍在，因此先恢复本地服务，再完成品牌和前端改版。新视觉参考用户的 [yeuxark.com](https://yeuxark.com/) 首页：鱼形标识、灰纸底色、手写文字与克制的印泥红。

用户先要求 handdraw #70 与 #97 两个方向；看到首稿后要求继续生成 #97 变体，最后明确选择 C「侧身阅读」。保留其余设计供日后比较。

## Spec：验收要求

- 名称、首页、页头、网页标题、书架导出名称统一为 Sardina。
- 一条沙丁鱼与漫画书构成主体，图形不带生成文字，Sardina manga 字标由 HTML 排版。
- 主视觉采用用户选定的 C；A、B 和首稿可比较、下载。
- 搜索、推荐、排行榜、最近更新、书架、源目录与阅读器操作区使用一致的纸色与墨线。
- 保留封面墙暂停与选书、原有书架和阅读进度，以及阅读器明暗背景选择。
- 1280、393、320 px 宽度不出现横向溢出，导航和主要操作保持可用。
- 本地服务可重复启动并脱离终端会话运行，提供状态、停止与日志入口。

## Impl：交付内容

### Logo 与颜色

使用 handdraw-style-prompter 的编号风格资料与参考图，通过内置 imagegen 生成。#70 采用连续线条、抽象形态和符号化；#97 采用极简轮廓、松弛日常与轻微超现实的手绘表达。生成文件按原样保存为透明 PNG。

| 文件 | 用途 |

| `web/brand/sardina-097-a.png` | A，正面抱书 |
| `web/brand/sardina-097-b.png` | B，卷尾小鱼 |

| `web/brand/sardina-070.png` | #70 首稿 |

所有方案在 [本地品牌页](http://127.0.0.1:8765/brand) 比较、下载。中英提示词与参考图记录保存在 [首稿提示词](../output/branding-20260923/logo-prompts.md) 和 [#97 变体提示词](../output/branding-20260923/logo-097-variants-prompts.md)。

读取 yeuxark.com 的实际样式后采用以下颜色：纸底 `#d8d3cc`、浅纸 `#e7e3db`、边线 `#b4ada1`、墨色 `#1b1815`、次级文字 `#3b352f`、印泥红 `#8c3a2c`。参考样式来自 [paper.css](https://www.yeuxark.com/assets/css/paper.css)，本地留存于 `output/branding-20260923/yeuxark-paper.css`。字体使用本机手写、楷体与系统回退，不引入外部字体请求。

### 页面与阅读体验

`web/index.html` 接入 C 的首页图形、页头图形及 favicon，保留全部 49 个唯一交互 ID。`web/home.css` 调整首页与手机布局；新增 `web/sardina.css` 统一其余页面和弹窗。封面墙降低饱和度，中心用纸色提高搜索区辨识度；原有暂停和选书功能继续使用。

阅读器仅调整操作区、设置和章节目录的颜色及按钮样式，保留深浅阅读背景、宽度、翻页和图片布局。用户原有浏览器存储键不变，书架、阅读进度、设置继续沿用。

`web/app.js` 与备份提示完成用户可见名称更新；项目清单名称为 `sardina-manga`。后端仅调整服务名称和明确的静态资源白名单，未扩大为任意目录访问。

### 启动与维护

服务地址仍为 [http://127.0.0.1:8765/](http://127.0.0.1:8765/)。可双击根目录的 `启动 Sardina.command`，也可运行：

```bash
.venv/bin/python scripts/sardina_service.py start
.venv/bin/python scripts/sardina_service.py status
.venv/bin/python scripts/sardina_service.py stop
```

启动器将服务与终端会话分离；重复启动复用现有服务。PID 与日志位于 `output/runtime/`，停止操作只针对本项目启动器管理的进程。它不提供开机自启，机器重启后需再次启动。已实测停止、重新启动、重复启动和状态查询；交付时保持服务运行。
