# 从本地 APK 吸收功能：审计、规格与实施

目标：缩短找书、继续阅读和切换阅读方式的操作，同时保留云漫现有轻量界面、全源搜索与本地数据。

## 审计基线

云漫代码已有全源搜索、逐源重试、章节搜索、连续滚动、明暗/宽度/沉浸、进度恢复、书架导入导出。当前缺口是：书架只有最近/标题排序，没有查找和阅读状态；首页不能直接回到上次阅读；阅读器仅支持连续模式；全源搜索固定队列，用户不能优先使用常用源。

APK 研究由两个 Agent 分别核对代表性 App 的资源/类方法，以及原生、Flutter、H5 壳与组件声明。扫描本地 174 个 APK 的 ZIP 资产目录，核对 10 个代表包的身份与结构；其中 MyComic、Komikku、Cimoc、阅读四款进一步核对了 57 个 DEX 方法体、15 份布局/菜单，65 个内部证据引用均可解析。未安装运行 APK，故这些是静态实现证据，不代表原应用的实时服务或手势体验已验收。

完整 [功能研究小结](../output/apk-product-study-20260921/data-audit-summary.md)、[功能与证据矩阵](../output/apk-product-study-20260921/data-feature-audit.json)及 [壳与资源审阅](../output/apk-product-study-20260921/shell-report.md) 均保留具体 APK、实际包版本、资源路径和方法位置。

| 借鉴点 | 本地实现证据 | 云漫的实现取舍 |
|---|---|---|
| 最近阅读与收藏分开 | Komikku 查询按 `historyView.readAt` 取最近记录，`favorite` 独立；Cimoc Favorite/History Presenter 调用不同列表 | 新漫画打开详情不入架；明确收藏或成功阅读时入架；实际阅读使用 `readAt`，首页只显示一条继续入口 |
| 书架分类与查找 | Komikku CategoryRepository 写入分类；阅读 BookGroupDao 查询书组；MyComic 收藏/历史布局 | 采用在读、想读、已读三个状态，不增加复杂的多层分组；状态独立于页码 |
| 连续与逐页 | Komikku 的 LEFT_TO_RIGHT/RIGHT_TO_LEFT/WEBTOON/CONTINUOUS_VERTICAL；Cimoc PageReader 索引翻页与 StreamReader 按屏滚动；MyComic 方向设置布局 | 连续默认，逐页适配完整页；只改变翻页操作方向，不倒排图片；全局设置保留模式、背景与宽度 |
| 常用源 | Komikku SourcePreferences 真实读取 `pinned_catalogues`；Mihon/Komikku 置顶资源 | 只优先下一次请求队列，保留全部 25 源；排序不等于源响应更快 |
| 备份 | Cimoc 布局分开漫画、设置、标签；Komikku 备份结构区分历史和偏好 | 继续使用书架 v1，增加可选状态字段；阅读与分类各自按时间合并，仍可导入旧备份 |

没有发现可直接接到当前云漫后端的完整壳：阅读系/异次元确有辅助 Web 书架，但依赖 App 的 getBookshelf/getBookContent 等服务；再漫画的包依赖 uni-app 原生运行时；多数主 App 是 Android 原生或 Flutter AOT。合集文件名“云漫 v2.5.4”实际包名为 `com.mansou.cimoc.ym`，不能按同名认作论坛原项目。此次交互均在现有 Web 模块中独立实现。

## 本轮规格

1. **书架整理与继续阅读**：增加名称/作者/来源查询及“全部、在读、想读、已读”筛选；每本书可修改状态。打开新漫画详情不再直接加入书架，详情可明确“加入书架”，实际阅读成功后也自动保存。旧记录全部保留，按是否已有阅读进度自然归类，不丢失章节、页码和页内位置。首页只在有可继续的记录时显示一条继续阅读入口。备份保留新增状态，旧格式继续可导入；合并时分别保护较新的阅读进度和状态选择。
2. **两种阅读方式**：连续滚动保持默认；新增适合页漫的逐页阅读和可见的翻页操作。切换模式保留逻辑页，设置集中到一个面板。现有取消请求、最多4并发、图片释放、失败重试、恢复保护继续生效；不自动跨章或全量预取。
3. **常用源优先**：在现有源目录中选择优先源，下一次搜索优先排入队列，其余已接入源仍全部检索。选择仅改变顺序，不改变源注册数或搜索覆盖。

先做这三个闭环。更新提醒、后台同步、批量离线下载、社交/签到等不进入本轮界面。

## 界面约束

沿用蓝白漫画书架风格，封面仍是主要视觉元素：背景 `#f5f9ff`、纸面 `#ffffff`、主色 `#2677ed`、文字 `#243b58`、次级文字 `#71829a`、分隔 `#dce8f6`。字体沿用系统中文字体，标题、书名、说明保持现有层级。

首页在搜索区下方放一条轻量的继续阅读入口；书架标题下直接放查询与状态，不增加首页导航。阅读器顶部保留返回、设置和沉浸，设置展开后再显示模式、背景与宽度。手机与桌面使用相同词汇和操作顺序，320px 下无横向溢出，所有控件可用键盘操作。

## 分工与验收

- 主 Agent：书架模型、兼容迁移、首页继续阅读、主应用接线、精确静态路由、文档与浏览器验收。
- reader Agent：阅读模式、设置面板、图片与进度状态、相关测试。
- data Agent：代表性 APK 功能证据与适用性审计。
- search Agent：壳/资源复用审计，随后实现常用源优先模块。

验收覆盖旧书架与备份迁移、较旧备份不覆盖新进度、状态修改不移动阅读位置、分类空态与查询、继续阅读恢复、首末页及快速切模式、加载失败与切章取消、常用源优先且全源仍搜索。浏览器使用独立会话及合成普通内容验证，不修改用户浏览器的书架。完成后记录实际通过项与仍有的限制。

## 实施结果与验收

已完成上述三组功能，并保持原页面蓝白风格。书架查询与分类直接放在书架中；备份操作收进可展开区域；阅读设置按需打开，逐页模式保留可见翻页按钮；常用源放在现有源目录的“当前搜索源”区域。没有新增首页导航或引入前端框架。

- **自动测试**：259 项 Python 回归通过；68 项 JavaScript 测试通过。静态路由覆盖本轮新增模块，JS 语法检查通过。
- **浏览器**：43 项交互断言通过，详见 [浏览器结果](../output/playwright/apk-product-20260921/browser-results.json)。使用独立 Playwright 会话、合成漫画与图片，实际读取云漫 25 源注册表。共四轮搜索、100 次合成搜索请求；优先源先请求，每轮 25 源完整保留。
- **位置与请求**：旧记录第 3 页、0.6 页内位置恢复；连续→逐页→连续保持位置；左右方向不逆转图片；首末页不自动跨章；新章逐页只请求当前图；同页在途切换未重复请求；跨章后晚到响应不改写当前进度。
- **失败与备份**：注入两次 HTTP 429，错误可见且未覆盖有效进度；新作品首图失败不制造阅读记录，重试成功后正确入架。真实导出文件保存 v1、新分类及时间戳；真实导入旧文件保留较新页码和分类。
- **视觉与键盘**：1200px 桌面、393px 与 320px 手机截图已查看；书架、源目录、阅读器及设置无横向溢出；设置焦点闭环、Escape 关闭面板及沉浸返回通过。浏览器没有未捕获脚本异常；控制台仅有两次预期的合成 429。

交叉审阅另修复了两个实际问题：首次阅读的分类时间戳原本没有写入，旧备份可能将其改回想读，已增加回归测试；章节目录搜索框的 Escape 原本可能只清空输入，现直接关闭当前面板且不连带退出阅读。

## 保留的边界

阅读模式与常用源仍是当前浏览器的全局偏好，没有实现每本书独立设置。导出的是书架，不包括阅读器设置与常用源；旧记录只有 openedAt 时只能沿用已有时间，无法重建历史真实阅读日期。逐页以完整一页适配屏幕，长条漫画可选连续模式。仍未加入后台追更、批量离线或跨设备同步。

本轮不改变源注册或上游可用性结论，仍为 25 源；COLAMANGA 等未通过完整阅读验证的来源仍未启用。
