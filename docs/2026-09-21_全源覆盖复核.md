# 云漫全源覆盖复核：清单、搜索、目录与真实图片

核验日期：2026-09-21（北京时间）。本报告补充并收紧[前轮源覆盖报告](2026-09-21_原版源覆盖与搜索漏检.md)的结论。

**当前原版公开启用的 12 个源，本地均已注册；但功能尚未全部对齐。** 本轮 9 个源取得普通漫画真实图片经本地代理完整解码的证据。拷贝漫画当前受限，Komiic 修复后的真实图片受配额阻碍，歪歪图片仅有合成测试。把“18 个源”或“原版清单 12/12”直接理解为“全部可读”是不成立的。

## Intent：证明没有漏源，同时查明名义接入与实际体验的差距

用户已遇到原版能搜到《富家女姐姐》、本地不能的问题。前轮定位并补上唯一准确命中的歪歪源，本轮进一步核对是否还有隐藏的清单遗漏，以及已登记源是否真的能完成搜索、目录、阅读。

验收必须分四层：源身份集合 → 同作品搜索 → 同作品章节集合 → 真实图片。每层记录独立证据；增加 APK 源、增加模糊结果或取得逻辑图片 URL 都不能补偿下一层失败。

## 审计方法与源清单

同时取得原版 `/api/sites`、首页、7 个公开业务 JavaScript 文件及三组真实聚合搜索。公开清单、首页源图标映射、搜索实际返回的源 ID 集合均为相同的 12 个：

`baozimh`、`mangacopy`、`dm5`、`mangabz`、`manben`、`manhuagui`、`comicbox`、`manhuazhijia`、`tuku`、`rumanhua`、`hipmh`、`komiic`。

原版优先级数组另外出现三个标记，已逐一排查：`manhuazhan` 和 `kanman` 被原版搜索界面明确排除；`copymanga` 仅出现于排序数组，没有活动注册、返回结果或别名转换证据。因此不把它们误计成三个遗漏的活动源。本地额外的 6 个 APK 源另算，不用于抵消原版缺源。

证据：[清单及代码锚点](../output/source-audit-20260921/original-source-inventory.json)、[原版独立审计](../output/source-audit-20260921/original-audit.md)、同目录下的页面及资源 SHA-256 清单。公开客户端不能证明服务端不存在未公开或未启用的内部适配器，本报告不作该承诺。

## Spec → Impl：审计发现的修复及验收条件

| 优先级 | 问题及验收条件 | 实现 |
| --- | --- | --- |
| P1 | 动漫屋/漫本目录有图但代理 403；同一真实图片修后可解码 | 从已校验的图片查询参数 `cid` 生成对应章节页 Referer，不从图片存储路径猜章节 ID |
| P1 | Komiic 一次为整章索票、票据放在 URL，导致浪费配额并 401；只为实际需要的页索票，票据进入 `X-Image-Ticket` | 独立适配器；目录只返回本地逻辑标记；并发与缓存有界；真实元数据通过，成功图片由合成 HTTP 回归验证 |
| P1 | 图片代理错误被 `<img>` 隐藏成笼统失败；配额原因应直接可见，每页单次请求 | 阅读器改为可取消的 fetch，读取安全错误文本，成功 Blob 解码，完成/关闭/切章释放资源；不自动重试失败页 |
| P1 | 正文倒序、番外置首、卷话交错；连续阅读先按正文号进行 | 只使用明确章节名/分组排序，保留未知条目原位置和同编号相对次序；不从数据库 ID 猜故事顺序 |
| P1 | 拷贝 APP 受限时未区分功能失败；不能静默吞成空成功 | 保留成功 APP 的全分组分页；仅明确业务码 210 时使用正常官网协议，空目录/阅读返回可见原因，不改身份或权限参数 |
| P2 | 原版嬉皮移动链接无法打开目录，旧深链丢失书名导致换源查找使用“漫画”占位词 | 校验并读取 mid；已记录的公开详情接口返回同作品 ID 后补齐书名、作者、封面、简介及状态；资料故障保留目录并显示原因 |
| P2 | 12/12 被理解为实时可用率 | 页面改为“原版清单”；接口新增 `scope=registered-source-ids`、`liveAvailabilityChecked=false`；日志不记录包含图片票据的查询串 |

章节排序不盲目应用于漫画柜、图库和嬉皮：这些源混有不同版本，早期内容可能只有单行本。简单“单话优先”会跳过故事开头。当前保留这些源的可读内容与源顺序，版本选择列为剩余体验差距。

## 尚未达到的验收与继续条件

1. **拷贝阅读未对齐：** 原版聚合服务能返回目录，本机 APP 及匿名官网当前不能。官网使用页面原始参数及正常会话仍是空目录、空 `contentKey`，不能用合成解密成功宣称问题已解决。源站恢复当前访问后，才能完成同书目录集合及真实首图复验；不通过改身份、权限参数或伪造章节绕过限制。
2. **Komiic 图片仍待复验：** 公开协议与受控测试已修正；当前配额耗尽后已停止真实索票。配额恢复后只需一个普通作品页面经本地代理的完整解码验证，不需再为整章索票。
3. **歪歪真实阅读未验收：** 正确搜索和逻辑页不是实际像素可读的证明；报告保留未验证状态。
4. **版本组织仍有差距：** 漫画柜、图库、嬉皮的单话/单行本/重制版需要独立阅读路径及切换，不能只按原版排序抄齐；这不属于源身份遗漏。
