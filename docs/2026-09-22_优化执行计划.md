# 云漫成熟度优化：执行计划与验收

日期：2026-09-22。依据：[质量审计](2026-09-22_成熟漫画软件对标与质量审计.md)。

## Intent：这一轮交付什么

保护已有书架与进度，让不完整源响应不会伪装成功；让同源旧地址继续关联进度；将固定两源轮换升级为有界多源候选与本地兴趣推荐；改善阅读顺序、手机适配、章节状态和追更。保持首页简洁、原生前端与现有 25 源覆盖。离线下载、跨设备同步、协同过滤属于后续独立阶段，不在本轮引入未经验证的基础设施。

## Impl：并行分工与改动边界

- 主任务：计划、书架存储／备份／稳定身份、前端别名、目录追更、应用整合、缓存接线、浏览器与最终回归。
- 源数据 Agent：`client` 源适配（不改推荐模块）、对应 Python 测试；提供目录完整性与语言字段。
- 推荐 Agent：`client/recommendations.py`、`web/recommendations*`、新增反馈模型及对应测试；向主任务说明服务端缓存与应用接线需求。
- 阅读器 Agent：`web/reader*`、对应测试；使用稳定身份和明确序列字段，避免改 `app.js` 引发冲突。
- 每组先根据审计触发条件建立失败用例，再修实现，运行相关测试；主任务交叉复核接口，不以调整测试掩盖未解决问题。

## 数据兼容与回退

实现前源码快照：`output/iteration-20260922/before-source.tar.gz`，文件摘要同目录。新格式读取旧 v1，迁移不得删除旧存储；无法解析的原始记录保留恢复入口。浏览器验收使用独立测试会话和合成书架，不清空用户当前书架。旧地址合并以源内可信 ID 为依据；跨源版本关系不确定时不自动迁移页码。
