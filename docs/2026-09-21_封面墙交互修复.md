# 封面墙交互修复

用户反馈背景无法暂停、无法选择漫画。

## 核查

封面不可选是明确的实现缺口：原组件丢弃了作品标题和详情地址，使用 `span` 绘制封面，并将整个区域设为 `inert` 与 `pointer-events: none`。

原右下角独立暂停按钮在隔离浏览器可冻结动画，但仅有 36px 图标入口，没有悬停暂停，也不记住手动选择。此次扩大并明确入口，增加选书时暂停与手动选择持久化。在联调中还修复了焦点切换时重建按钮子节点导致点击丢失的问题：控件 DOM 保持稳定，仅更新图标和状态。

## 当前行为

- 背景封面保留真实作品身份，点击打开现有漫画详情；鼠标停在封面上时整面墙暂停，移开后恢复。
- 右下角固定显示“暂停／播放”，按钮至少 44px 高；手动暂停或播放保存在当前浏览器，刷新后保留。无手动偏好时遵循系统减少动态设置。
- 封面悬停或键盘聚焦时变清晰并显示标题；点击打开详情后保持暂停，方便关闭详情继续选书。
- 键盘只停在可见的作品副本，重复滚动组不会产生 64 个停靠点。Enter 可打开详情。
- 封面地址或身份无效时不创建可打开的入口；失效图片不成为可点击目标。离开首页隐藏控件并暂停背景。

## 验证

JavaScript **126/126** 测试通过，包含作品身份保留与非法详情地址过滤。浏览器 **17 项**桌面／手机宽度交互检查、**6 项**独立触控模式检查通过：实际指针悬停与离开、动画冻结、刷新保留暂停、真实目录打开、返回、键盘、320px 控件布局、触屏单次点击与减少动态偏好。

真实样本：点击《鬼灭之刃》封面，请求漫画之家对应详情地址，取得 **212 章**目录，关闭后返回首页并保持暂停。没有请求真实章节图片。触控测试使用隔离上下文、合成目录和图片，用户当前阅读页面与书架未用于测试。
