# Sardina Web 上线记录

访问地址：<https://manga.yeuxark.com>。应用运行在独立的 `sardina.service`，使用 Nginx 提供 HTTPS，已启用开机启动与异常重启。

## 部署版本与环境

- 应用代码：`1e60f45`，版本目录 `/opt/sardina/releases/20261006-1e60f45`。
- Ubuntu 24.04、Python 3.12、Node.js 22；依赖从 `uv.lock` 导出，并校验安装包哈希。
- 以专用低权限用户运行；应用仅监听 `127.0.0.1:8765`。
- 通过 `--public-origin` 显式允许公网域名，保留原有本机入口及跨站请求限制。
- 独立 Let's Encrypt 证书，有效期至 2027-01-04；自动续期演练和续期后 Nginx reload 均通过。

后续更新及回退见 [部署说明](DEPLOYMENT.md)。

## 验收

- 本机：427 项 Python 测试、215 项 JavaScript 测试及语法检查通过。
- 公网：首页、前端模块、发现页面与配置接口返回 200；不匹配的 `Origin` 返回 403。
- 《三月的狮子》：25 个搜索源全部返回响应，1 个源失败；精确作品合并为 11 个来源。
- 漫画巴士：获取 219 个章节，第一话解析出 31 页；封面及首张正文图片均为有效 JPEG。
- 浏览器：验证首页、搜索、来源切换及进入阅读器；首张正文正常显示，保留验收截图与页面快照。
- 运行检查：服务 active/enabled，无异常重启；验证时占用约 49 MiB。
- 共存检查：其他 Nginx 站点配置哈希未改变，原主站仍返回 200。

本地证据保存在 `output/deployment-20261006/` 与 `output/playwright/sardina-vps-*`，不提交到仓库。

## 已知边界

此验收验证部署和代表性阅读链路，不代表每个漫画源都可用。首页有两张来自包子漫画 CDN 的背景候选封面返回 502，页面使用其余可用封面；Cloudflare 注入的分析脚本被现有 CSP 拦截，不影响漫画功能。

书架、进度、推荐偏好和下载仍分别保存在每个浏览器。迁移旧书架需要先在本机导出，再到公网网站导入；下载图片不会随 JSON 备份迁移。网站没有账号同步，重新打开应用仍需网络连接。
