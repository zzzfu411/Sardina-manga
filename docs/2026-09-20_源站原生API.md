## JSON / 正式 API

### hipmh / Comichub — `https://hipapi1.s3file.top`

```
GET /v1/search?q=
GET /v1/home
GET /v1/manga?mid=bTo0Mjk2          # 详情，mid 必须是 token
GET /v1/manga?slug=yi-quan-chao-ren-4288
GET /v1/manga/chapters?mid=4296&page=1&per_page=20&order=asc
GET /v1/recommend?genre=4
GET /v2/chapter?hid=YzoxMDUzNDg-NDI5NjoxLjAw   # 或 ?cid=105348
```

`/v1/chapter` → 410。v2 hid = `b64(c:{cid})-{b64url(mangaId:order)}`。  
`data.images` 密文 → `chapter-decoder.js` / `window.__cimg.r` → 相对路径，拼 `https://hip-tx-1.s3imgs.top`。

### 拷贝 — 必带头 `platform/version/region/webp`

```
GET https://api.mangacopy.com/api/v3/search/comic?q=&limit=&offset=&q_type=
GET https://api.mangacopy.com/api/v3/comic2/{path_word}?platform=1
GET https://api.mangacopy.com/api/v3/comic/{path_word}/group/default/chapters?limit=&offset=&platform=1
GET https://api.mangacopy.com/api/v3/comic/{path_word}/chapter2/{uuid}?platform=1
```

`contents[].url` 明文。

### Komiic — `POST https://komiic.com/api/query`

`searchComicsAndAuthors` / `comicById` / `chaptersByComicId` / **`imageTicketsByChapterId`**（url+ticket+expiresAt）。

### 如漫画 — JSON + 混淆图

```
POST http://rumanhua2.com/s          {k: keyword}
POST http://rumanhua2.com/morechapter {id: comicId}
GET  /data/rank  /data/sort
```

章节 HTML packer → XOR(`keys[data-id]`) → JSON URL 列表。HTTPS 证书不对，用 HTTP。

## HTML / ashx（没有 REST，但协议完整）

| 源 | 搜索 | 章节 | 图 |
|---|---|---|---|
| 包子 | `GET /search?q=` | `/comic/{id}` → `page_direct?comic_id&section_slot&chapter_slot` | `amp-img` bzcdn |
| 之家 | `GET /search?q=` | `/comic/{slug}` `/chapter/{id}` | `img[data-src*=scomic]` |
| 图库 | `GET /search?title=` | `/manga-{id}/` `/chapter{cid}/` | 页内完整 `image*.tuku.cc` |
| 歪歪 | `GET /search?keyword=` | `/book/{id}` `a.sp-chapter-item` | HTML `.jpg` 是逻辑地址；真文件 `{page}.b_0`+`.b_1` AES-CBC `key=aaaaaaaaaaaaaaaa iv=0123456789aaaaaa`，再竖切 N=44..80 |
| 柜 | `GET /s/{kw}.html` | `/comic/{id}/` | packer 第 4 参 LZString → `SMH.imgData` → hamreus `?e=&m=`（不能离线签） |
| 动漫屋 | `GET /search?title=` | `/m{cid}/` | `chapterfun.ashx` + `DM5_*` 会话，每次 1–2 张 |
| 巴士 | 同上 | `/m{cid}/` | **`chapterimage.ashx` + `MANGABZ_*`**（不是 DM5_） |
| 漫本 | `GET /search?title=&language=1` | `/mh-{slug}/` `/m{cid}/` | `chapterfun.ashx`，无日漫一拳 |
