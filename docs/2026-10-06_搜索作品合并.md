# 搜索中的重复作品

《装备我最强》被拆成多条结果，主要因为各源的作者署名长短不一，旧分组要求作者字符串完全相同。另有三个问题：繁体书名没有完整归一化，漫画巴士把相邻的作者链接连成一个姓名，瓜子漫画返回了二次转义的括号。

## 调整

- 同一标题下，能够唯一归属到完整署名的短署名合并到同一作品。较完整的署名之间须有至少两名共同创作者；共同工作室或出版社不能单独充当这一证据。
- 不通过一串间接的作者重叠合并作品；能匹配多个不同作品的短署名保留独立。未知作者不能把冲突作品连接起来。
- 保留原版自译、外传、全彩等标题差异，以及来源明确提供的版本、语言信息。
- 作者中的实体、括号、加号和重复署名统一处理。相邻作者链接用分隔符连接，英文姓名内部的空格保留。
- 主列表每部作品显示一张卡片，所有来源保留在“更换来源”中。数量按不同漫画源计算，同一源的不同条目仍可切换。

## 验证范围

2026-10-06 从线上采集的样本包含 11 个源、14 条普通版本记录和 1 条“原版自译”记录。普通版本合为一条，原版自译单独保留；逐个加入详情作者资料后，分组仍然稳定。没有依赖《装备我最强》的专用标题别名或作者名单。

回归覆盖完整搜索样本、结果到达顺序、详情补全、未知或冲突作者、共同出版社、间接重叠、版本和语言边界。浏览器场景覆盖折叠来源、补全资料后保持已选来源、正文入口、章节排序，以及 393/320 像素宽度下的布局。

运行完整验证：

```bash
python scripts/check.py --browser
```
