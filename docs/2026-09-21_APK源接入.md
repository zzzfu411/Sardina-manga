# APK 源接入：意图、约束与验收

## Intent

将用户在 `output/apk-sources/` 中提取的漫画源信息转化为云漫可实际使用的搜索、目录和阅读能力。沿用已有作品聚合、失败隔离、图片代理及阅读进度；保留提取资料作为规则来源。

## 审计

- 已有 11 个原生源适配器，前端从 `/api/sites` 动态加载，无需重写搜索或阅读器。
- 提取资料包含 Legado 63 条、怪兽 72 条、异次元 77 条；归并目录有 91 项。来源间存在别名、相同域名、旧接口和加密规则。
- Cimoc 的 155 项是域名配置，不能据此生成可运行的搜索和阅读适配器。
- 需要逐源确认：当前域名、搜索结构、完整章节列表、章节图片、图片防盗链及正常的登录/付费限制。
- 原有 URL 和图片代理白名单必须随新源精确扩展，不能开放任意域名。

## Spec

1. 每个启用的源提供稳定的 `siteId`，输出现有搜索、详情、章节图片契约。
2. 搜索保留标题、作者、封面、最新章节等真实字段；不存在的字段保持空值。
3. 目录去重并按阅读顺序输出；不混入推荐作品或伪造可读章节。
4. 图片 URL 经过现有代理；按源设置 Referer，并检查重定向、格式与大小。
5. 网络错误、接口变化、登录/付费限制必须有明确反馈，不能伪装成搜索无结果。
6. 用固定响应测试解析逻辑，用真实请求验证至少一部作品的搜索 → 目录 → 图片链路；浏览器再验证产品集成。
7. 提取文件仅作为开发资料，不在应用启动时执行其任意 JavaScript，也不依赖 APK 文件在发布目录中存在。

### 实现与数据语义

- 看漫画、漫画台、神漫画共用同族有效 HTTPS WAP 网关，通过独立产品参数区分，元数据和返回图片具有各自品牌标记。漫画台/神漫画旧移动域证书过期，服务端不直接请求其过期入口，也没有关闭 WAP 的 TLS 校验。
- WAP 目录中存在小数点章节编号，解析器保留它们；按源站排序并去重，避免漏掉中间章节。
- 漫客栈无结果页面附带推荐书目，已识别并排除，避免制造搜索命中。
- 再漫画保留完整分组和阅读权限。部分作品 `canRead=false` 时可以查看目录，但阅读接口明确说明受限；另三部公开作品已经验证可返回图片。
- 快看旧移动页现提供桌面 Nuxt 状态。实现只解析字面量、参数引用、数组占位和有限赋值，不使用 `eval` 或执行站点脚本。完整目录含锁定章节，名称标记“源站受限”，详情与搜索卡片提示限制；锁定章节不会把预览图当作完整章节返回。
- 新增图片域名、Referer 及签名参数保留已接入现有代理。原有 URL、重定向、MIME、大小限制继续生效。
- 原生模式新增源不会进入云漫兼容模式的搜索、详情或图片请求，避免旧收藏切换模式后调用不支持的上游。

### 测试与浏览器验收

- Python 回归共 85 项通过；JavaScript 搜索及阅读器回归 32 项通过。新增样本覆盖分页去重、目录顺序、权限拒绝、章节身份、域名边界和受限状态解析。
- 六个新源均通过真实云漫 HTTP 接口的搜索 → 目录 → 章节图片 → 同源图片代理检查。不是只测独立解析函数；封面和首图均检查状态、MIME 和文件头。
- 桌面浏览器已显示 17 个源；《妖神记》看漫画卡片显示 963 章，按正序直接打开第 1 话，阅读器成功渲染 800 px 宽真实图片并显示 14 页。按视口加载图片，后续页面不抢先全部下载。
- 手机端在 393 × 852 视口验证快看《谷围南亭》：120 章、权限提示与受限标记正常；免费首章 172 页，真实首图宽 1280 px，首次视口加载 4 张，无横向溢出。
- 已将最终代码启动到用户使用的 `http://127.0.0.1:8765`，复核 `/api/sites` 返回 17 个源，并再次通过看漫画搜索、目录、章节及首图代理。独立联调服务使用 8767，验收后关闭。
