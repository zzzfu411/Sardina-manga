# 发现源扩展：审计、规格与实施

## Intent

用户发现排行榜和最近更新只有两源，要求尝试接入其余已接入搜索的源并完善体验。本轮检查全部 25 个现有搜索源的真实发现能力，能验证的接入，未接入的逐源提供具体证据与原因。

## 审计

- 搜索注册和实际请求分发均为 25 源；发现模块独立写死漫画柜、漫本两源，未复用其他源的榜单或更新入口。
- 参数校验只认识漫画柜周期，并一律限制热门列表第一页，阻碍其他站的真实分页与不同周期。
- 前端已经支持来源能力驱动的类型／周期，但封面失败统一请求两源专属补图接口，扩源时必须区分是否支持从作品页补图。
- 推荐池也固定为两源；本轮优先完善用户指出的排行榜与更新来源，推荐池是否扩充以实际已验证列表为依据，避免发现页启动时批量请求所有站点。
- 源站的“排行”“热门展示”“最近更新”“最新上架”含义不同。只有真实榜单/热门列表接入 popular，只有有章节更新语义的列表接入 latest；不伪造名次、时间或完整范围。

## Spec

1. 保留全部搜索源，新增发现适配按源声明 `modes`、真实周期和分页上限；不接受任意上游 URL。
2. 每条作品包含准确的来源和作品地址，封面取源返回的真实地址，顺序保持源站原样。源站未给名次时不补造数字。
3. 固定首页展示区明确说明取样范围；真实下一页必须验证，不以重复第一页或失败结果冒充结束。
4. 每个选择只读取当前列表，接口缓存沿用五分钟；采用有界请求和大小限制，不批量下载漫画、不触发图片票据。
5. 新源封面失败可重试原图片；只有明确支持作品页补图的来源才调用补图 API。
6. 失败隔离、取消、迟到响应保护和手机布局继续有效；搜索／书架／阅读接口保持兼容。
7. 对全部 25 源记录：排行、更新、周期／分页、封面、详情衔接及当前未接入原因。已注册源与现场可用性分别表述。

## Impl 计划与责任

1. 三个独立任务按现有适配家族检查公开站点、已有 APK/规则证据，保存真实 HTML／JSON 和当前访问结果。
   - HTML：动漫屋、漫画巴士、包子、漫画之家、图库、如漫画、歪歪。
   - APK 中文：看漫画、漫画台、神漫画、漫客栈、再漫画、快看、漫画1234、可可、瓜子、6漫画。
   - API／官方：嬉皮、Komiic、拷贝、Sunday Webry、泰拉记事社、NamiComi。
2. 主任务提供共享有界传输，整合三个独立适配模块，扩展能力校验与 UI 封面重试／范围说明。
3. 每个启用来源保存固定响应解析测试；测试真实分页、未知字段／周期拒绝、空结果和错误区别。
4. 每新增来源抽取一部作品验证现有详情衔接，仅目录元数据，不请求章节图片。访问受限如实保留。
5. 运行完整 Python／JavaScript 回归，再用隔离浏览器检查多源切换、分页、真实封面、重试和 320px 布局。
6. 更新当前运行服务、README 和本报告的实际覆盖矩阵，最终交付准确数量和剩余限制。

## 实施结果

此前只有两源的原因是发现模块只实现了漫画柜和漫本的适配；25 源搜索注册没有自动带来各源的榜单与更新能力。本轮已补齐其余 23 源的可验证发现入口，合计 **25 个发现源、24 个排行榜／热门来源、24 个更新来源**，搜索仍为原有 25 源。三个独立适配任务完成逐源核查，主任务整合、回归和浏览器验收。

- 后端由每源能力声明决定模式、周期和页码；不再把所有热门列表限制为第一页。新增适配使用共享有界传输，单列表一般只请求一次，看漫画额外探测下一页，最多两次且共享超时。原有五分钟缓存继续使用。
- 前端直接展示源站提供的封面；新增源图片失败可单独重试，不再误调只支持两源的补图接口。周期、分页和有限栏目范围由真实返回值控制。
- 源目录显示每个搜索源已经支持的发现功能；主页文案保持简洁，不增加源数量宣传。
- 修复 6漫画详情解析中落后的封面域名白名单，避免从榜单打开详情后封面丢失。
- 修复如漫画部分目录以最新话开头的问题：只有原站“开始阅读”指向末项，且至少三个明确编号章一致递减时才整体反转；详情层在开始链接和升序再次确认后保留这一源序，避免通用分类导致局部跳号。完整 430 项实测目录从“预告 → 设定图 → 001话”开始，390 个可识别编号均升序、章节 URL 集合不变；证据不足不猜顺序。

## 验收与证据

1. **新增 44 个来源／模式组合现场读取全部成功**：HTML 分组 14 个、APK 中文分组 19 个、API／官方分组 11 个。API 分组另测不同周期和分页，总计 23 个真实选择；APK 分组另用本轮保存的真实响应回放 32 种模式／周期组合。所有这些返回项都有通过校验的源站封面 URL，这不等于逐张下载过图片。
2. **目录衔接**：23 个新增来源中抽查 22 个普通作品目录，全部非空。歪歪本轮仅检查列表元数据。未请求章节图片或 Komiic 图片票据，不能据此声称全部作品阅读链路已验收。
3. **自动回归**：完整 Python 测试 371 项、JavaScript 测试 134 项通过；覆盖源身份、模式／周期／分页、错误与空结果区分、URL 校验、缺图重试、迟到响应和如漫画目录顺序。
4. **隔离浏览器控制场景**：56 项检查通过，覆盖来源选择、周期与范围说明、翻页、迟到响应隔离、封面失败重试与缺图、源目录能力展示、320px 无横向溢出。该轮在再漫画人气榜追加前检查了 47 个来源／模式组合；最终真实浏览器再次确认两种模式分别有 24 个来源。
5. **真实浏览器**：17 项检查通过。包子、漫客栈、Komiic、再漫画、6漫画的真实列表可见，五源首两张封面完整解码；6漫画作品打开 80 项真实目录后返回仍保留选择与封面，更新第一页 48 部且第二页不重复。真实手机页面无横向溢出、无未处理脚本异常。一张后续加载的 6漫画封面曾返回 502，单独重试已返回正常 JPEG；源站偶发失败仍提供单张重试。
6. **当前运行服务**：2026-09-22 15:25（北京时间）已重启原 8765 端口，11 项检查通过：25 个发现源、24／24 种模式、25 个搜索源保留、源目录能力一致、未支持模式明确拒绝、包子真实列表与封面地址成功返回，所有修改过的页面文件和工作区一致。

## 保留的边界

- 推荐页仍使用漫本与漫画柜的既有池；本轮扩展的是排行榜和最近更新，不在打开页面时并行抓取全部 25 源。
- 图库当前返回的更新日期为 2025-12-06，嬉皮近期更新有“2周前”等原始文字，均未改成今天。获取时间表示本地读到列表的时间，和作品更新时间分开。
- 漫画台／神漫画网站证书过期，使用现有证书有效的品牌 API 网关，未关闭 TLS 校验。如漫画继续使用已验证的公开 HTTP 入口。
- 拷贝本次普通作品目录已成功读取；部分作品可能限制匿名目录。快看、NamiComi 等既有作品权限提示保留，发现列表不承诺受限章节可阅读。
- 名称不同的品牌源可能共享作品库；保留各自来源身份，但不把它们视为互不重叠的作品总量。
