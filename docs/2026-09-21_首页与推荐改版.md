# 首页与推荐改版

后续交互已按用户反馈调整：封面可点击打开详情，支持悬停暂停和手动暂停记忆；本页初版的“纯装饰／不可点击”约定由 [封面墙交互修复](2026-09-21_封面墙交互修复.md) 取代。

## Intent

首页承担搜索入口，删去源数量、背景点击提示、宣传语与重复说明。用缓慢流动的真实漫画封面作为唯一主要视觉元素。发现功能移到独立页面，推荐书必须展示漫画封面并能沿现有详情／阅读链路打开。

## Spec 与设计

- `/`：云漫标题、搜索、已有搜索历史及继续阅读；不显示榜单列表、源数量、分类标签或宣传语。背景装饰封面不成为移动点击目标，提供暂停控制，尊重减少动态效果偏好与后台暂停。
- `/discover`：推荐；`/discover/popular`：排行榜；`/discover/latest`：最近更新。使用导航与三个明确入口；支持刷新、直接打开、前进／后退，以及详情关闭回到对应页面。
- 推荐池来自已接入来源的真实人气榜／更新页，只接受带有效封面地址的书，保留逐条依据并按标题去重。过滤已收藏作品；当前推荐依据为真实热门和更新，不包含个性化模型。支持换一批、失败重试与封面加载失败处理，不预取漫画目录或章节。
- 后端请求与缓存有界，单源失败不拖空其他推荐，全部失败明确展示错误。搜索仍为原有 25 源。

颜色：冰蓝背景 `#f5f9ff`、白色 `#ffffff`、主蓝 `#2677ed`、正文 `#243b58`、辅助文字 `#71829a`、细线 `#dce8f6`。系统中文无衬线字体；首页只突出云漫标题，搜索直接可见，发现页由封面承担视觉主体。壁纸四条平行封面带错向缓慢移动，中心柔和留白，其他界面不增加动画。

复核：移除原先口号胶囊、分类标签、功能说明与源统计，避免用装饰性文字填充。保留蓝白漫画主题，把变化集中在封面墙；推荐与榜单不再堆在搜索下面。没有新增登录、评分系统或模型调用来增加使用负担。

## Impl 与验收

数据 Agent 实现真实推荐书池并实测封面代理；界面 Agent 实现推荐选择、封面卡片与取消；动效 Agent 实现独立封面墙；主 Agent 完成页面路由、精简首页、接口和视觉联调。

验收覆盖：主页删文案和推荐页面分离；独立路由与详情返回；真实推荐封面解码；缺图重试、请求取消与批次保持；320px／393px／桌面布局；减少动画偏好、暂停／恢复、离开首页暂停；原有书架、发现与阅读流程回归。

## 实际结果

已完成并运行于 `http://127.0.0.1:8765`。

| 需求 | 实现与验收 |
| --- | --- |
| 首页文案简洁 | 删除源数量、宣传语、分类标签、背景点击提示和技术页脚；保留云漫、搜索及已有历史／继续阅读。 |
| 流动漫画墙 | 四条封面轨道交错移动；重复组无缝循环。手动暂停、减少动态偏好、后台和离开首页暂停均通过；失效图片隐藏对应副本，不反复重试。 |
| 独立发现页 | 推荐、排行榜、最近更新各有路由；直接访问、刷新、浏览器后退以及详情返回均通过。 |
| 有封面的推荐 | 实际接口返回 24 本、两类真实依据，无来源警告；每批 12 本，桌面六列、手机双列，换一批无重复；书架过滤保留其他版本或明确不同作者的同名书。 |
| 失败恢复 | 单源失败保留另一源；全部失败显示错误。刷新失败保留原卡片；封面失败自动尝试一次替代，再提供单卡重试／换一本；取消后的迟到响应不改写当前页面。 |
| 原有流程 | 推荐可打开《妖神记》261 章真实目录；合成图片验证进入阅读、保存书架、返回详情／推荐、首页继续阅读。隔离搜索验收仍发出 25 源请求。 |
