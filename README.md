# Sardina manga

本地漫画搜索与阅读应用。最初对照 [LINUX DO 项目帖](https://linux.do/t/topic/2919011) 实现，现以 Sardina manga 为产品名称，纸张与手绘视觉延续 [yeuxark.com](https://yeuxark.com/) 的风格。保留接口研究资料与原生源适配层。

## 启动

需要 Python 3.11+、[uv](https://docs.astral.sh/uv/)；嬉皮章节解码还需要 Node.js 在 PATH 中。

```bash
git clone https://github.com/zzzfu411/Sardina-anime.git
cd Sardina-anime
uv sync
.venv/bin/python scripts/sardina_service.py start
```

打开 **http://127.0.0.1:8765**。默认 `native` 模式直接访问漫画源，不依赖 mangayun.com 聚合 API。

macOS 可双击根目录的 **启动 Sardina.command**，会启动服务并打开浏览器。启动器将服务与终端会话分离，重复启动会复用已运行的服务；它不是开机自启服务。查看状态使用 `.venv/bin/python scripts/sardina_service.py status`，停止使用 `.venv/bin/python scripts/sardina_service.py stop`。运行日志在 `output/runtime/sardina-server.log`。开发时仍可前台运行 `uv run python server.py`。

Logo 采用用户选定的 handdraw **#97 C「侧身阅读」**：一条沙丁鱼与漫画书。初版 #70、#97 及追加三稿可在本地 `/brand` 比较、下载；资产位于 `web/brand/`。更名保留原有浏览器存储键，旧书架、进度和设置继续使用。

品牌方案、前端改版和本轮验收见 [Sardina 品牌与前端改版](docs/2026-09-23_Sardina品牌与前端改版.md)。

```bash
# 兼容已有云漫客户端，用于比对原站接口；依赖原站服务及签名规则
uv run python server.py --provider mangayun --port 8766
```

服务仅监听本机，未做公网部署。更换端口会使用另一份浏览器本地书架，迁移时请导出、导入备份。原生模式与兼容模式的部分源地址格式不同，切换模式后可能需要重新搜索入架。

## 已实现

- 简洁搜索首页、缓慢流动的漫画封面墙、搜索历史与继续阅读；封面可点击打开漫画，悬停或键盘选择时暂停，手动暂停选择会保留到刷新后。支持减少动态偏好及桌面／手机布局。
- 独立发现页：`/discover` 推荐、`/discover/popular` 排行榜、`/discover/latest` 最近更新，支持直接打开、刷新恢复和详情返回。
- 推荐轮换使用 25 源的发现列表，每次最多 6 列表、来源并发最多 3、本地候选池最多 200，每批展示 12 本。候选耗尽可补充；用本地作者与内容线索、明确收藏、近期曝光和多样性排序，支持不感兴趣、撤销、关闭偏好与清空推荐记录。卡片展示真实来源理由与封面，封面失败可重试或切换已知来源。
- 推荐复用实际打开作品的资料；对支持轻量资料接口的 7 源，每轮最多补取 2 本，先展示卡片再补充作者、简介与题材，不拉取整本目录。曝光惩罚随时间衰减，保留相关度和近期阅读失败信号；本地分别统计开始阅读、连续阅读、阅读失败和恢复。偏好、忽略、撤销及清空以增量操作跨标签合并；清空记录保留明确的偏好开关。
- 发现列表覆盖全部 25 个现有搜索源：24 源支持排行榜／热门列表，24 源支持最近更新。按源提供真实周期与分页，保留原站顺序、名次和时间；首页栏目、今日／七日更新等有限范围直接说明。统一展示真实封面，单张失败可重试；漫画柜与漫本缺图时按可见范围从作品页补取。
- 25 个源的应用适配入口：含 2026-09-21 原版公开源清单的全部 12 个源，以及 13 个 APK / 规则新增源；逐源搜索、筛选、失败隔离、重试和停止搜索。
- 页头“源目录”可查询 99 条新规则、29 个插件及 9 份协议资料的接入状态、对应来源和未启用原因；资料条数与实际搜索源数量分别显示。
- 源目录内可查看各搜索源的排行榜／更新能力，并星标常用源，下一次搜索优先请求；全部 25 个已接入源仍参与搜索，不缩减结果覆盖。
- 源目录显示实际搜索、目录、章节与图片请求的最近结果、时间和耗时；空搜索与请求失败分别记录，封面与正文图片分开，最近 15 分钟内最多 32 次观测的失败不会被随后一次成功抹掉。本地图片排队超时不计为源站失败。可可漫画已接入经验证的 `keke2026.com`，保留旧地址作为作品身份，兼容原有书架与阅读链接。
- 按作品聚合搜索，精确标题与受控繁简/异名优先；跨源在卡片内切换，相关和其他结果可展开。
- 搜索卡片按需加载目录，直接点章节阅读；详情请求并发最多 2，返回的新源不会重置已选源和排序。
- 手机搜索默认折叠全部源筛选与作品的其他来源，保留当前选择及全部源入口；状态分别显示已响应数量与失败数量。
- 漫画目录、章节筛选、排序、换源查找；嬉皮完整分页、拷贝多分组分页。
- 连续与逐页阅读；当前页优先，标准模式向后预读连续 6 页／逐页 3 页，可选多预读或省流。阅读与下载共用最多 4 个图片网络请求，下载最多占用 2 个；内存图片缓存有 24 MiB 上限，同图请求合并。Komiic 与浏览器省流偏好在标准模式下只加载可见页。逐页支持左右阅读方向，模式切换保留当前页及页内位置。
- 章节下载：在详情或阅读器选择起始章节，下载 1／3／5 章；在书架的“下载管理”中暂停、续下、阅读或删除。排队任务、目录和逐页图片保存到当前浏览器，完成后断开外网仍可阅读；本地 Sardina 服务仍需运行。下载图片上限 1 GiB，配额不足时提示且保留已有下载，关闭页面后暂停，重新打开可继续；图片不包含在书架 JSON 备份中。清除站点数据会移除下载。
- 下载数据库自动升级到 v2：同书目录共享、列表只读摘要，多标签以 Web Locks 协调同章下载。续下重新取图片清单，已验证的漫画巴士图片票据更新可复用本地页；未知内容变化保留旧版，直到新章完整保存后再替换。下载管理分别展示图片预算、浏览器配额与持久存储状态。
- 部分下载遇到过期图片地址时，阅读器自动更新清单再重试；完整下载保持离线可读。在线目录移除的已下载章节仍可从下载管理或原阅读链接打开，孤立本地章不会猜测相邻章节。在线打开本地章节后后台更新目录，并可手动“更新目录”，不移动当前页。
- 漫画巴士章节图片地址按最多 4 路并行解析，按页码合并并检查缺页、重复和超出声明页数，缩短打开章节的等待。
- 跳页、可搜索章节目录、单页/整章重试、前后章与沉浸模式；逐页的首末页边界不自动跨章。坏图解码失败后移除对应缓存，单页重试重新取图；整章重试刷新清单，空或无效清单不进入成功缓存。
- 阅读器提供适宽／整页、100%–300% 放大、双击放大与平移；设置按单本保存，可设为全局默认。具有明确语言序列的目录不会自动跨语言跳章，仍允许从目录手动选择其他语言。
- 阅读进度保存到页内位置；恢复到后段不会先加载所有前页，切章和关闭会取消旧请求，失败不覆盖有效进度。
- 阅读图像只保留当前页附近的显示窗口，远处页面保留尺寸占位，回翻按需恢复。翻页进度只持久化当前一本，不重新解析全书架，也不逐页重建推荐画像。
- 详情页可加入或取消收藏，取消收藏保留阅读进度；书架支持“只看收藏”。仅浏览详情不会新增记录，成功开始阅读会保存阅读记录。逐章已读可明确标记和撤销，与页位置、整本分类、更新提示分开。首页提供最近一本在读漫画的继续入口。
- 书架按书名、作者或来源查找，按“在读／想读／已读”筛选与标记；保留全部旧记录。移出后可短时撤销，空状态能清除全部筛选或前往搜索。书架每页最多 48 本、详情与阅读目录每页最多 80 章，查询覆盖全部数据；隐藏的阅读目录不创建条目。应用内关闭详情、阅读器返回已有父页面；搜索与阅读深链接、刷新恢复继续可用。
- 书架可手动检查更新、停止、重试失败和只看有更新；可选择启用打开应用时自动检查常读连载，每本至少间隔 6 小时，每轮最多 20 本、并发 2，不读取章节图片。完整目录的部分锁定不再阻断追更。更新提示与阅读完成分别管理。
- 版本 2 JSON 书架导出/导入，兼容旧 v1；保存阅读进度、收藏、逐章已读、分类与目录检查记录。移除 300 本静默截断，采用逐本存储、删除标记和跨标签合并；阅读会话及后台目录更新保留删除代次，旧页面的退出保存不会撤销另一标签的删除。旧原始书架保留，支持导出恢复记录；存储失败会提示。备份读写统一为 50 MB 上限，不包含阅读设置、推荐反馈和常用源偏好。
- 嬉皮可信新旧作品地址关联到同一条记录，漫画柜、Komiic、拷贝使用可靠源内作品 ID；搜索保留官方副标题命中。未知跨源版本保守分开，不自动照搬不同版本的页码。
- 声明页数不足、重复章节分页和 HTML 访问挑战不再作为完整成功或空搜索缓存；合法无结果仍正常返回。
- 同源图片代理，限制图片域名、重定向、类型与大小；同 key 请求合并，有效缓存不等待无关慢请求。后端元数据请求与图片请求分别最多 8 路，图片后台任务最多占 6 路，为当前页保留 2 路，共享任务可提升优先级。打开阅读器时暂缓未完成的封面，关闭后恢复；图片缓存上限 32 MiB，前端现有并发与缓存预算仍生效。
- 本地 HTTP 服务与检查入口共用 64 条待接收连接队列，避免页面集中加载模块时因默认小队列产生连接重置；它独立于上述漫画源并发预算。
- 章节解析使用有界的已知格式解析器，不再执行源站任意表达式；证书验证失败明确报错，不自动降级为不验证连接。
- 歪歪漫画独立适配器：搜索、完整目录及章节地址；图片代理支持分片解密、头部恢复及切片重排，缓存版本取自当前源页面。

浏览器验收自动启动临时端口和独立临时浏览器，使用合成图片与拦截响应，不访问线上漫画源、不修改日常书架。结果默认保存至 `output/checks/`；成功与失败均写 `summary.json`，浏览器场景失败保留阶段、截图、DOM、控制台、失败请求与 trace。线上源抽样单独执行，本轮结果见[交付记录](docs/2026-09-26_复审修复交付记录.md)。GitHub Actions 在推送与拉取请求时执行相同检查，报告保留为 `regression-evidence` 构建产物。

仓库包含源码、测试、品牌资产和开发文档，不包含 APK、浏览器书架、下载漫画、运行日志或环境文件。审计文档中的 `output/` 链接指向本地验证产物，可通过上述命令生成新的结果；历史代码行号对应当时的审计版本。

升级到 0.4.0 后请刷新所有已打开的 Sardina 标签，使跨标签保护同时生效。书架及下载沿用原键名与数据库；推荐反馈读取旧 v1，在正常写入时升级为 v2，保留已有偏好。旧源码不能读取新版推荐反馈，不应把回退源码当成数据回退。现代浏览器使用 Web Locks 保证并发合并；不支持 Web Locks 的环境仅提供同步读改写降级。

## 目录

- `server.py`：本地 HTTP 服务、路由、缓存、图片代理。
- `client/providers.py`：将已有源脚本规范化为搜索、详情、章节 API。
- `client/comicbox.py` / `comicbox_images.py`：歪歪 HTML 解析及独立图片还原管线。
- `client/komiic.py`：真实作品元数据、卷话区分及按需图片票据，不预支整章配额。
- `client/mangacopy_web.py`：拷贝正常匿名官网适配，明确保留源站未返回目录/图片的状态。
- `client/chapter_order.py`：按明确章节名及分组排列阅读顺序，保留未知条目。
- `client/source_coverage.py`：区分原版源覆盖、新增源和总源数；支持当前线上清单核对。
- `client/source_health.py`：按能力记录实际请求结果和延迟，原子保存到 `output/runtime/source-health.json`。
- `client/request_budget.py`：前台保留额度、有界后台并发、同请求提升与公平排队。
- `client/apk_wap.py` / `apk_dmzj.py` / `apk_kuaikan.py`：从 APK 和图源规则接入的独立适配器。
- `client/apk_sunday.py` / `apk_official_catalogs.py` / `apk_vomic_html.py`：新解包资料的七源适配器。
- `client/source_catalog.py` / `source_catalog.json`：公开资料清单与当前接入状态，不加载或执行原始规则。
- `client/discovery.py`：发现源注册、能力与参数校验、漫画柜／漫本列表和作品主封面解析；接口缓存由服务端管理。
- `client/discovery_common.py`：发现列表的有界元数据传输和公共校验；`discovery_html.py` / `discovery_apk.py` / `discovery_api.py`：其余 23 个来源的真实列表适配。
- `client/recommendations.py`：有界多源候选、有效封面筛选、来源条目去重与失败隔离；发现列表缓存由服务端复用。
- `client/serialized_state.py`：受限解析快看 Nuxt 数据，不执行远端 JavaScript。
- `web/`：原生 JavaScript 前端，无额外构建步骤。
- `web/search-model.js` / `search-view.js`：作品相关性与跨源聚合、搜索卡片及按需目录。
- `web/library-model.js` / `library-store.js`：分类、逐章状态、版本化备份、逐本持久化和跨标签合并；`book-identity.js`：可信源内身份与保守作品关联；`library-auto-updates.js`：自动追更筛选。`web/source-preferences.js`：常用源持久化与完整搜索队列排序。
- `web/discovery.js` / `discovery-model.js` / `discovery-covers.js`：发现列表、分页、按需补图、重试和取消；`web/library-updates.js`：目录指纹、变更确认、有限并发与迟到响应保护。
- `web/recommendations.js` / `recommendations-model.js`：卡片、候选补充与书架过滤、封面重试；`recommendations-ranking.js` / `recommendations-feedback.js`：本地排序与可撤销反馈；`recommendations-metadata.js`：有界作品资料缓存。`web/cover-wall.js` / `cover-wall.css`：封面墙、暂停及动态偏好；`web/home.css`：首页与独立发现页布局。
- `web/reader.js` / `reader-transport.js`：阅读状态、可取消的图片加载、错误原因与进度恢复。
- `web/cover-pause.js`：阅读时暂缓后台封面；`route-history.js`：弹层历史所有权；`page-window.js`：有界列表分页。
- `tests/`：分页、源失败隔离、缓存、输入校验、HTTP 路由回归。
- `tests/browser/` / `scripts/check.py`：真实浏览器回归与统一验收入口；`.github/workflows/checks.yml`：持续检查配置。
